# ars autocamiones

Este proyecto es una aplicación diseñada para la gestión y administración de productos disponibles en una tienda, tales como camionetas, busetas y repuestos. El sistema permite llevar un control eficiente del inventario, facilitando la organización y el registro de los diferentes productos que la empresa ofrece.

## Características principales

- Registro y gestión de productos (camionetas, busetas, repuestos, etc.)
- Control de inventario y disponibilidad
- Panel de control intuitivo y generación de reportes

## Requisitos previos

- Tener instalado [Node.js](https://nodejs.org/) y npm
- (Opcional) Tener instalado [Git](https://git-scm.com/) para clonar el repositorio

## Instalación y puesta en marcha

1. **Clonar el repositorio:**

   ```bash
   git clone https://github.com/Zednanreh0911/Proyectazo-2.git
   cd Proyectazo-2
   ```

2. **Instalar dependencias en ambas carpetas:**

   - Para el cliente:

     ```bash
     cd client
     npm install
     ```

   - Para el backend:

     ```bash
     cd ../backend
     npm install
     ```

3. **Configurar las variables de entorno** (si aplica):

   Crea un archivo `.env` en cada carpeta (`client` y `backend`) y agrega las variables necesarias según la documentación interna del proyecto.

4. **Iniciar los servidores de desarrollo:**

   - Para el cliente:

     ```bash
     npm run dev
     ```

   - Para el backend (en otra terminal):

     ```bash
     npm run dev
     ```

5. **Acceder a la aplicación:**

   - Abre tu navegador y entra a la dirección que indique la consola (por lo general, `http://localhost:3000` para el cliente y otro puerto para el backend).
